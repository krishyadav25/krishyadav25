## Featured Projects

### [Deepfake Detection](https://github.com/krishyadav25/deepfake-detection)
Image-forgery detection using complementary visual features and attention-based feature fusion, with model evaluation and threshold analysis.

**Technologies:** Python, PyTorch, OpenCV, scikit-learn

### [Networked Robot Teleoperation](https://github.com/krishyadav25/networked-robot-teleoperation)
A terminal-based robot teleoperation project using TCP communication, heartbeat monitoring, emergency-stop handling, and communication-loss safety behaviour.

**Technologies:** Python, TCP/IP, automated testing

### [Image Captioning](https://github.com/krishyadav25/Image-Captioning-Model-)
An image-to-text generation project exploring CNN/RNN attention approaches and transformer-based captioning.

**Technologies:** Python, deep learning, NLP

A full-stack application for 3D MRI analysis, combining preprocessing, 3D U-Net segmentation, graph-based feature extraction, Graph Attention Network (GAT) severity prediction, and report generation. The application uses a React and TypeScript frontend with a Python FastAPI backend.

**Technologies:** Python, PyTorch, MONAI, PyTorch Geometric, React, TypeScript, FastAPI
