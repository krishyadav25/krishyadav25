## About

I'm **Krish Yadav**, a Computer Science student specialising in **Artificial Intelligence and Machine Learning** at UPES Dehradun.

I enjoy turning technical ideas into working projects—from computer-vision models to safety-aware robot control. I care about the full problem-solving process: understanding the problem, building the system, testing it, and explaining what the results actually show.

- **Focus areas:** Machine learning, deep learning, computer vision, and networked robotics
- **Currently building:** A networked robot teleoperation system with command handling and safety mechanisms
- **Approach:** Practical engineering, measurable evaluation, and continuous learning
- **Outside code:** Formula 1, games, and exploring how technology works
